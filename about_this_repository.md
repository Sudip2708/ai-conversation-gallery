# Conversations to Art

A collection of AI-assisted conversations that evolve into visual artworks.
Each entry preserves both the final image and the thought process that led to its creation.

This repository is not just a gallery of images, but a structured archive of dialogue, reflection, and transformation — where conversation becomes form.

---

# Structure

Each artwork is stored in its own folder:

```
YYYY-MM-DD_Title/
    _original_conversation/
    *.md
    *.png
```

Inside each entry you will find:

* final artwork (image)
* original conversation (Markdown)
* structured bilingual documentation (CZ / EN)
* visual variations if applicable

---

# Purpose

This repository serves as:

* visual archive of AI-assisted creativity
* documentation of conversational processes
* experiment in structured thought-to-image transformation
* long-term creative journal

---

# Languages

Entries are maintained in:

* Czech (primary reflective language)
* English (global accessibility)

---

# Note

Each entry is self-contained and immutable once published, preserving the integrity of the original creative process.
